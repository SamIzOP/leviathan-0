# Baseline critique — 23 October 2026

Captured all 11 authored cameras and four additional inspections at 1920 × 1080; every image was opened and reviewed before designing the replacement. Camera coordinates and renderer statistics are in `before/views.json`. `map-before.svg` and `level-before.json` preserve the actual input data (3,189 colliders, 1,606 authored ornaments; raw object count is not useful dressing density).

No ordered mission path or sequential encounter gates enforce a longer journey.                                                                                                                                                                                                                                     |

Additional verified problem: the previous seal includes invisible collision-only perimeter extensions from 12 to 64 m. These conflict with the new visible-barrier requirement and must be replaced by rendered structure. The movement module also clamps world coordinates to ±120; the requested 420 × 340 m compound cannot fit that existing coordinate guard. This conflict needs an explicit recorded world-bound decision while preserving movement mechanics and all feel constants.

The redesign should preserve the street composition and weather treatment, while replacing the open asset fields, uncollided reachable ornaments, undersized secondary routes and single-beat traversal.

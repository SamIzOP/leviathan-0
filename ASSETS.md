# Optional world assets

The game runs with no files in `packages/client/public/assets`. Its procedural world, generated textures, sky, particles and synthesized audio are the default. No remote CDN or downloaded art is required.

`packages/client/public/asset-manifest.json` lives outside that optional directory. It maps model keys, surface texture sets, HDRI candidates and audio keys to same-origin URLs. Missing, malformed or unsupported files retain the fallback. Run `npm run assets:check` for a per-path report. Restart/reload after adding or replacing assets; a production build copies public files into dist.

## Layout and naming

| Directory under public/assets                         | Default names                                                                      | Guidance                                                                                                                                                                              |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| models                                                | crate.glb, container.glb, car.glb, van.glb, barrel.glb                             | GLB preferred; glTF with local sidecars also works. Use Y-up, metres, no cameras/lights. Keep typical props below 20k triangles and 1 MB.                                             |
| textures/brick, concrete, asphalt, metal, wood, glass | albedo.jpg, normal.jpg, roughness.jpg, ao.jpg                                      | Tileable PBR maps, 512–1024 px recommended. Albedo uses sRGB; other channels are linear. Change manifest extensions for PNG or KTX2. Metal includes desaturated rust in the fallback. |
| hdri                                                  | sky.hdr, sky.exr                                                                   | Equirectangular, 1k–2k recommended. First valid candidate supplies sky and PMREM reflections.                                                                                         |
| audio                                                 | rain.ogg, roof.ogg, wind.ogg, machinery.ogg, steam.ogg, crane.ogg                  | Quiet seamless loops; mono positional emitters, stereo rain/wind. WAV/MP3 also work when supported by the browser; update manifest paths.                                             |
| audio                                                 | footstep-asphalt.ogg, footstep-concrete.ogg, footstep-metal.ogg, footstep-wood.ogg | Short, normalized without clipping, approximately 0.1–0.3 seconds. Wet exterior steps retain the synthesized splash layer.                                                            |

Model keys use `prop.<kind>`. Each matching authored collider instance is replaced only after successful loading. The renderer scales the model independently on all three axes to the collider AABB, centres X/Z and snaps its minimum Y to the collider bottom. Author a matching silhouette to avoid distortion or collision mismatch. Imported geometry is visual only; it never changes shared collision. Global cold grading and grime still apply. Geometry with missing/invalid files remains procedural. A key with no authored instances (currently barrel) is supported for future level data but does not create objects by itself.

Draco decoding uses `/decoders/draco/`; KTX2/Basis uses `/decoders/basis/`; Meshopt is bundled in the client. These files ship locally from the installed Three.js distribution. Decoder READMEs include upstream license references; Three.js and Meshopt use MIT, Draco and Basis Universal use Apache-2.0. Preserve the bundled notices when redistributing. Compressed payload formats are wired to their loaders; the acceptance fixture exercises uncompressed glTF replacement and AABB fitting.

## Credits record

When supplying third-party art, create `assets/CREDITS.md` with one row per asset or set:

| Manifest key / files              | Work and author                  | Original source URL    | License and license URL         | Changes                                     | Acquisition date |
| --------------------------------- | -------------------------------- | ---------------------- | ------------------------------- | ------------------------------------------- | ---------------- |
| prop.example / models/example.glb | Exact credited title and creator | Original download page | Exact license/version and terms | Rescale, decimation, texture edits, or none | YYYY-MM-DD       |

Keep required license text beside the asset. Do not label unknown provenance as CC0. The current optional assets directory contains no external art; procedural content is generated by this project. Existing font licenses remain under public/fonts. Optional menu background files use the pre-existing menu pipeline and are independent of the world manifest.

## Inspection

F4 → WORLD / LOOK adjusts exposure, cold tint and effects. Operator Settings → Graphics selects LOW/MEDIUM/HIGH/AUTO and grain/bloom amounts. The service readout reports procedural/loaded prop paths for diagnostics. Asset replacement, empty-folder rendering and environment audio are covered by the reports linked in ACCEPTANCE.md.

## Model forge and export

Open /?gallery=1 with development tools enabled to inspect all 63 environment assets and their three variants. The seed changes deterministic wear/serial and debris variation. The silhouette, wireframe, collider overlay and dimensions use metres; the reference is 1.8 m tall. LOD1 removes ornamental details and uses simpler radial primitives. Gameplay additionally culls distant detail batches.

Run npm run forge:export to regenerate all 189 GLBs in packages/client/public/assets/models/generated and their manifest.json. These generated models are original project assets; no third-party credits are required for them. GLBs contain mesh geometry, material factors, UVs and collider metadata. Runtime procedural textures are not baked into the GLBs. The generated files are optional and are not fetched during normal fallback play.

Every catalog model has a prop.<key> entry in the main asset manifest. A valid GLB at that entry overrides its authored instances; otherwise the forge builds them. To use an exported variant later, point the corresponding main manifest key to its generated path. The previous prop.car path remains an alias for the sedan. No asset installation is required to play.
